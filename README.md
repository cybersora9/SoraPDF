# SoraPDF

**Pobierz / Download: [SoraPDF-setup.exe](https://github.com/cybersora9/SoraPDF/releases/latest/download/SoraPDF-setup.exe)** – Windows 10/11, 64-bit.

> To program na Windows. / This is a Windows program.

Merge, split, rotate and shrink PDFs – your invoices and contracts stay on your computer.
Połącz, podziel, obróć i zmniejsz PDF – faktury i umowy zostają na Twoim komputerze.

- No network, no telemetry, no account. / Zero sieci, zero telemetrii, bez konta.
- Not code-signed yet: Windows SmartScreen may warn – **More info → Run anyway** (details in the release notes).
  Instalator nie jest jeszcze podpisany: **Więcej informacji → Uruchom mimo to** (szczegóły w opisie wydania).
- Check the file: `SHA256SUMS.txt` next to the installer. / Sprawdzenie pliku: `SHA256SUMS.txt` obok instalatora.
